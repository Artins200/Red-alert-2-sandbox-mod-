# Что реализовано, а что нет

Коротко: всё, что вообще можно сделать штатными INI-файлами игры — сделано. Всё, что требует правки
самого `gamemd.exe`, честно помечено как «нельзя» с объяснением, чем это заменено.

## Реализовано

| Возможность | Как сделано (ключи в `rules.ini` / `rulesmd.ini`) |
|---|---|
| Убрать лимит на супероружие | у `GACSPH`, `GAWEAT`, `NAIRON`, `NAMISL`, `YAGNTC`, `YAPPET`: `BuildLimit=-1`, `Power=0` |
| Мгновенная перезарядка супероружия | `RechargeTime` у `NukeSpecial`, `LightningStormSpecial`, `ChronoSphereSpecial`, `IronCurtainSpecial`, `GeneticConverterSpecial`, `PsychicDominatorSpecial`, `ForceShieldSpecial` → `0.05` (около 3 секунд) |
| Второй комплект каждого супероружия | клонирование типов: новые секции `<здание>2` (с `Image=` на ванильную графику) + `<супероружие>2`, регистрация в `[BuildingTypes]` и `[SuperWeaponTypes]` — пункт 24 меню, ключ `CloneSW` |
| «Красивые бомбёжки» | ядерный warhead `[NUKE]`: `CellSpread=14` (было 10 — радиус вырос почти в полтора раза); `[NukePayload]`: `Damage=1200` (было 600), `RadLevel=800`; `LineMultiplier=6` (было 2) — линия удара супероружия |
| Ширина коврового удара настраивается | пункт 20 меню, ключ `CarpetNuke` (1–10) |
| Открыть всю карту | `[MultiplayerDialogSettings] Shroud=no` + `[General] ShroudGrow=no` |
| Герои без лимита | `TANY`, `BORIS`, `YURIPR` → `BuildLimit=-1` |
| Бонусные здания без лимита | `GAOREP`, `NAINDP`, `NACLON` → `BuildLimit=-1` |
| Мгновенное строительство | `[General] BuildSpeed=.1` (было `.7`; меньше = быстрее) |
| Полный возврат денег | `[General] RefundPercent=100%` |
| Честный ИИ (фикс «читерской» сложности) | `MultiplayerAICM=100,100,100`, `AIVirtualPurifiers=0,0,0` |
| Удобные умолчания для скирмиша | `Money/MaxMoney`, `UnitCount`, `TechLevel`, `GameSpeed`, `AIPlayers`, `AIDifficulty`, `Crates`, `ShortGame`, `FogOfWar`, а также `[Skirmish]` в `RA2.INI` / `RA2MD.INI` |
| Режим зрителя (2 бота друг против друга) | `ShortGame=no` + открытая карта + совет «не строить базу» (см. README) |
| Возврат игры в ванильное состояние | резервные копии + `uninstall.bat` |

## Не реализовано (и почему)

### 1. Кнопка «Настройка» внутри идущей партии

Экраны, кнопки, боковая панель и обработка кликов в RA2/YR — это код в `gamemd.exe`. Формат `rules*.ini`
описывает *данные* (юниты, оружие, супероружие, параметры скирмиша), но не умеет добавлять элементы
интерфейса. Поэтому:

* настройки вынесены **перед** запуском: меню `SandboxMod.bat`, либо правка `config\sandbox.cfg` в блокноте;
* после правки файла настроек достаточно перезапустить игру (правила читаются один раз при загрузке).

Настоящая кнопка в игре требует расширения движка (проекты **Ares** / **Phobos**: DLL, которая
патчит `gamemd.exe` на лету, пишется на C++). Это отдельный масштабный проект, и он несовместим со
Steam-сборкой «из коробки» (нужен подменённый `gamemd.exe` и `Syringe.exe`).

### 2. Одна кнопка «запустить всё супероружие сразу»

Каждое супероружие — отдельная иконка со своим типом цели (ядерная шахта — по площади, хроносфера — по
юнитам, железный занавес — по своим, психо-доминатор — по площади и т.д.). «Слить» их в одно действие нельзя:
у них разные обработчики в движке, а INI не умеет создавать новые типы действий.

Что сделано вместо этого:

* перезарядка ~3 секунды — все иконки всегда готовы, «прокликать» шесть супероружий занимает несколько секунд;
* каждый удар ядерной шахты бьёт по линии шириной `CarpetNuke` (по умолчанию 6) и накрывает радиус в 14 клеток;
* карта полностью открыта, так что целиться в базу бота можно сразу;
* настройка `CarpetNuke=10` превращает один клик в настоящий апокалипсис.

### 3. Пункт «Sandbox» в списке сложностей

Список сложностей (Easy / Normal / Brutal) — тоже интерфейс, зашитый в exe: движок знает ровно три значения.
Добавить четвёртое через INI нельзя. Зато:

* сам мод целиком и есть «режим песочницы» — он включается на всех сложностях;
* сложность ботов ставится в меню мода (пункт 17) и на экране скирмиша;
* «фикс сложности» из запроса реализован отдельно — см. `BUGFIXES.md`, пункт про читерский ИИ.

### 4. Полноценный «фикс багов движка»

Часть известных багов RA2/YR живёт в коде (психоконтроль + разворачивание МСВ, сохранение скирмиша,
рассинхроны). Через INI они не лечатся — их правят Ares/Phobos/CnCNet-клиент. Что *можно* было
поправить настройками — поправлено, список в `BUGFIXES.md`.
