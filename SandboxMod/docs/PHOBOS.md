# Про Phobos и Ares: помогут ли они с «плюшками только игроку»

Короткий ответ: **нет, эти две проблемы они не решают**, и вот почему.

## Что такое Phobos

[Phobos](https://github.com/Phobos-developers/Phobos) — расширение движка Yuri's Revenge: набор
патчей, которые впрыскиваются в память `gamemd.exe` через Syringe/SyringeEx, плюс сотни новых
INI-ключей. Он не заменяет Ares, а дополняет его (хотя формально работает и без Ares). Проект живой
(последний коммит — октябрь 2026), но, по словам авторов, «не поддерживается достаточно активно».

Из документации проекта (`docs/New-or-Enhanced-Logics.md`, `docs/Miscellanous.md`,
`docs/Fixed-or-Improved-Logics.md`):

* поддерживается только **Yuri's Revenge** (движок `gamemd.exe`), про Red Alert 2 (`rules.ini`,
  `game.exe`) речи нет — этот режим мода пришлось бы выбросить;
* установка — это `Syringe.exe` + `Phobos.dll` (и обычно ещё Ares), а в Steam Launch Options
  прописывается `"...\Syringe.exe" "gamemd.exe" %COMMAND%`. Работает, но «папка + команда»
  превращается в «папка + инжектор + версии, которые должны совпасть».

## Чего в Phobos и Ares нет

Искал в их документации и в исходниках:

| Что хотелось | Есть ли |
|---|---|
| Скорость строительства **только для игрока** | Нет. В Ares `BuildSpeed` — это только глобальный `[General] BuildSpeed` (он же инвалидатор), в Phobos такого ключа нет вообще |
| «Эти правила действуют только на человека» | Нет, такой концепции нет ни в INI, ни в Phobos |
| Ограничение постройки зданий ИИ | Есть, но это обычный `AIBuildThis=no`, который мод уже использует |

То есть обе ваши проблемы — «КД только у меня» и «бот не должен развиваться быстрее» — Phobos не
закрывает: первая уже решена INI-клоном зданий (`SandboxSW=player`), вторая — правкой секций
сложности (см. `LIMITS.md`, раздел «Почему „только игроку“ нельзя сделать для общих правил»).

## Что из Phobos было бы действительно полезно

* `[General] AISuperWeaponDelay` — пауза, с которой ИИ проверяет свои супероружия (можно замедлить
  ИИ-супероружие, не трогая игрока);
* `SW.AuxTechnos`, `SW.NegTechnos`, `SW.TechLevel` — тонкие условия доступности супероружия;
* набор исправлений движка (в т.ч. часть багов из `BUGFIXES.md`, которые через INI не лечатся).

## Вывод

Мод остаётся INI-only: одна папка, никаких dll и инжекторов, работает и в YR, и в RA2, не ломается
от обновлений Steam. Если однажды захочется именно то, что умеет Phobos (тонкая настройка
супероружия, фиксы движка) — это отдельный, «продвинутый» вариант сборки, и его надо делать
осознанно: только YR, только с Syringe и только с зафиксированной версией игры.
