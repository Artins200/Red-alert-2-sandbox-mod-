# Настройки (`config\sandbox.cfg`)

Файл создаётся автоматически при первом запуске меню. Его можно править и вручную — игра подхватит
значения при следующем запуске.

```ini
[Sandbox]
Target=both
Superweapons=unlimited
SWRecharge=instant
Heroes=unlimited
BonusBuildings=unlimited
RevealMap=yes
BigBoom=yes
BuildSpeed=instant
SellRefund=100
FairAI=yes
Money=40000
UnitCount=10
TechLevel=10
GameSpeed=1
Crates=yes
ShortGame=no
FogOfWar=no
AIPlayers=2
AIDifficulty=2
CarpetNuke=6
GameDir=
```

| Ключ | Значения | По умолчанию | Что делает |
|---|---|---|---|
| `Target` | `both` / `yr` / `ra2` | `both` | для какой игры ставить правила. `both` — универсально, правильный файл подхватится при запуске |
| `Superweapons` | `unlimited` / `normal` | `unlimited` | снять лимит постройки и расход энергии у супероружий |
| `SWRecharge` | `instant` / `fast` / `normal` | `instant` | время зарядки супероружия: ~3 сек / 1 мин / как в оригинале |
| `Heroes` | `unlimited` / `normal` | `unlimited` | Таня, Борис, Юрий Прайм без ограничения |
| `BonusBuildings` | `unlimited` / `normal` | `unlimited` | обогатитель руды, промышленный завод, завод клонирования без ограничения |
| `RevealMap` | `yes` / `no` | `yes` | снять туман войны на всей карте |
| `BigBoom` | `yes` / `no` | `yes` | усиленные ядерные взрывы и ковровая бомбёжка |
| `BuildSpeed` | `instant` / `fast` / `normal` | `instant` | скорость производства (`instant` — почти мгновенно) |
| `SellRefund` | `100` / `50` | `100` | сколько процентов стоимости возвращается при продаже |
| `FairAI` | `yes` / `no` | `yes` | убрать читерские деньги у ИИ (см. `BUGFIXES.md`) |
| `Money` | число | `40000` | стартовые деньги в скирмише (10000 / 20000 / 40000 / 80000 / 100000) |
| `UnitCount` | `1` / `5` / `10` | `10` | юнитов на старте |
| `TechLevel` | 1–10 | `10` | максимальный техуровень доступной техники |
| `GameSpeed` | 0–6 | `1` | скорость игры (0 — медленно, 6 — быстро) |
| `Crates` | `yes` / `no` | `yes` | ящики с бонусами |
| `ShortGame` | `yes` / `no` | `no` | `yes` — игрок выбывает, как только снесён последний дом. `no` нужен для режима зрителя |
| `FogOfWar` | `yes` / `no` | `no` | «туман войны» (не путать с обычным туманом/шурудом) |
| `AIPlayers` | 0–5 | `2` | сколько ботов подставляется на экране скирмиша по умолчанию |
| `AIDifficulty` | `0` / `1` / `2` | `2` | сложность ботов по умолчанию: 0 — легко, 1 — средне, 2 — brutal |
| `CarpetNuke` | 1–10 | `6` | `LineMultiplier` у ядерного супероружия — «ширина» линии удара (в ванильных правилах 2) |
| `GameDir` | путь | пусто | если папка мода лежит **не** внутри папки игры — укажите путь к игре здесь |

## Отдельно про `RevealMap`

Движок реализует «открытую карту» через `Shroud=no`. У этого режима есть известный побочный эффект
(описан на ModEnc): карта считается «инвертированной», и оружие со свойством `RevealOnFire`
на короткое время наоборот **закрывает** участок туманом. В скирмише это почти незаметно, а
`ShroudGrow=no` не даёт туману наползать обратно.

Отдельно стоит знать: на паре карт авторы жёстко прописали туман внутри самого файла карты — на них
открытие карты может не сработать. Это редкость, но если встретили такую карту, ничего не сломается,
просто останется нормальный туман.

Если хочется чистого «родного» тумана — поставьте `RevealMap=no` и просто играйте с разведкой.

## Про `Money` больше 40000

Игра ограничивает стартовые деньги значением `MaxMoney` из правил; мод поднимает и `Money`, и `MaxMoney`.
Если поставить совсем большое число, на экране скирмиша список может показать старое значение, но старт
всё равно будет с заданной суммой. Надёжный диапазон — до 100000.
